# ニワゼキショウ類：他の白花種との局所的な同所性と、M種の紫白花色分布を調査線内で分離する

2026-10-13。**原著の花色と他種の関係はすでに2016年に発表されている**。ここでの成果は、公開された元の野外計数を使用し、群落間の大きな差や標本数だけで生じる関係かどうかを、地点年とさらに狭い「記録されたline（調査線）」の内部で再評価したことである。研究デザインは事後的・資料閲覧後で、外部事前登録ではない。

## 今回の現在地・結論

**空間構造は調査線内にも存在する。** 全512区から、M種の両色が存在する13地点年について前回PR182で確認した空間偏りを、調査線ごとのM紫白総数まで固定する条件付き帰無モデルで再検証した。その結果、11地点年の調査区間花色多様性のうち、調査線ごとの色型総数と各区の標本数だけでは説明されない成分は、地点年等重みで **+21.77ポイント（9,999回の無作為配置 p=0.0001）**。11地点年すべて正で、一つずつ地点年を外しても+18.55～+23.54ポイントを保つ。これは局所分布の記述と帰無モデル比較で、適応や独立進化の証明ではない。

**他の白花種L/Sの多い区と紫花M種の対応は、調査線内でも観測された。** 両型と他種の曝露に十分な観測がある8地点年（7つの名前付き地点）で、調査線内の紫M個体が存在する区のL/S相対頻度は白M個体の区より **+12.55ポイント**。8地点年すべて正。線内のM紫白総数と区ごとのM個体数・L/S個体数を固定して紫白ラベルだけ9,999回無作為配置すると、方向付き p=**0.0001**、主指標2つのHolm補正後 **0.0002**。同一の場所に複数年の観測があれば最新版だけ使用する感度分析でも、6地点で **+9.11ポイント、p=0.0001**。これは原著の広い種間頻度相関より厳格な **同一lineでの比較**であるが、同じ観察研究の追加解析であり、L/Sによる生殖干渉が因果的に生じたことの証明ではない。

**水辺からの距離が大きな制限である。** 各調査線でL/S相対頻度を距離に線形回帰した残差を使うと、8地点年の平均は **+1.00ポイント、単独の名目上p=0.0378**に縮小する。同じ調査線集合での調整前は+13.30ポイントなので約**92.5%の記述的な縮小**だが、因果的な「距離に説明された効果割合」とは呼べない。さらにBanpaku Y13を外すと**−0.058ポイント、p=0.5548**で非支持。8地点年の距離調整後の差が正なのは5地点年のみ。**「距離と独立した生殖干渉の一般的効果」には採用しない。**

## 出典・分析単位

Takahashi, Takakura & Kawata (2016), *PLOS ONE*, DOI **10.1371/journal.pone.0164381**。オリジナル公開Dryad DOI **10.5061/dryad.j8q34**、正当な公開Zenodo保存複製 record **5003124**。127,502バイトのZIPはMD5 **008ec196aa5acb769dbfd36e835e32ba**、内部 `data/frequency.txt` のSHA256 **a12cdf46483a6d8b78bd00110c196a25f3c8849967ae8a2c37d6aee3d29f516e**で認証。

512記録は、2011・2013年、13名称地点・16地点年。M種は紫v=5,081、白w=8,723、合計13,804個体。別種の白花L=4,463、S=29（Lが他種の**99.35%**）は**白M種に加算しない**。126区はM種がいない区であり、単色区ではない。調査区間比較は year×population×line×quad を最小観測単位とし、lineの中でも2区以上が対象種を持つ場合だけ評価する。lineと地点を独立な系統進化反復と見なさない。

原著ではすでに「L/Sが多いところでM種紫が多い」が報告され、水辺からの距離とL/Sの相対頻度は強く共変動するため、両者の独立した効果を同じモデルで判別できなかったと記されている。今回の距離線形残差検証も、その根本的な交絡を解決するものではない。

## 固定した2つの主比較と感度分析

1. **主比較：他種との局所同所性**。各有効なline内で `a=(l+s)/(v+w+l+s)` とし、紫M個体が経験するaの平均−白M個体が経験するaの平均を求める。line内に紫白両型とaの差が存在し、各lineのM個体数・色型数を維持した9,999回の超幾何配置を帰無とする。各地点年等重み。情報不足のlineと地点年は `HOLD` でありゼロ効果とはしない。
2. **副主比較：調査線内の花色の偏り**。観測された区間Gini–Simpson成分から、調査線間の頻度差と、各line内で標本数が小さければ偶然生じる期待区間成分の双方を差し引く。全11地点年で+21.77ポイント、Holm調整後p=0.0001。観察した花色の空間配置であって遺伝的F_STではない。
3. **予定済み距離感度**。各line内のaの線形距離成分だけを差し引く。その後p=0.0378は探索的かつBanpakuに依存し、強い機構結論に使わない。
4. **資料閲覧後の追加診断**。距離調整の分母となった同じline集合だけで元の平均を再計算して+13.30対+1.00ポイントを比較した。検定数を増やしたものではなく、サポート変化による数値の混同を避けるための台帳。

## 何を支持し、何を支持しないか

**支持**：調査されたSisyrinchiumのM種の色型配置は、同じ地点内で調査線を固定しても調査区間に偏っている。L/Sの多い調査区で紫M型が多いという元原著の傾向は、同じline内の限定された標本条件でも正の方向に見られる。

**非支持/未識別**：線形水辺距離を超えてL/Sが紫花増加を**直接引き起こした**、頻度依存選択、実際の送粉者の区別、交雑による適応度、遺伝子型に対応する、同一の種間効果がすべての場所で成立する。Boecheraでは前回PR182でJudd Falls一地点が全体効果を支配していることが分かっており、今回のSisyrinchium結果と合わせて「全球共通機構」を支持したとは言わない。

## 再現性

主コード `src/within_line.py`、別実装 `src/verify_independent.py`、出力 `results/result.json`、地点年台帳 `results/siteyear_support_and_effects.csv`、距離の同一サポート比較 `results/posthoc_matched_distance_support.csv`。別実装は `csv.DictReader` と分数計算から直接集計し、本解析コードをimportしない。元データのSHA256と期待値の小標本全列挙で数式を検証する。独立した新規野外調査や、論文に出ていない遺伝型データは存在しない。
