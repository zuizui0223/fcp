# 水辺からの距離は未知の植物個体群へも花色頻度を予測できるか

2026-10-13 / FCP 追加解析。**主要判定：同じ地点の未知調査線で成功した水辺距離モデルは、地点そのものを除外すると予測改善が安定しなかった。** 他の白花種の共存比率はこの6地点の未知地点対照では平均損失を最も下げたが、因果解釈はできない。

## 今回、何を新たに区別したか

前回PR #185では、同一地点の別の調査線の植物色型を予測した。これには、**評価地点で観察された他の調査線の色頻度**を学習に使えるという条件が付いていた。今回の比較では**対象の地点名を丸ごと学習集合から取り除いた**。この2設定を混同して「水辺距離は地理的に一般化する」と言わない。

同じ元調査区を厳密に固定し、6地点名、各地点の最新の適格年、32調査線、168調査区、M種紫・白合計6,692個体を評価した。前回の地点内予測と今回の地点外予測で**評価区は完全同一**だが、利用できる訓練集団の情報が異なる。4モデル（基準BASE / 水辺距離DIST / 他の白花L+S種比率CONGEN / 両方BOTH）、Ridge λ=10、訓練区のみでの標準化、Jeffreys切片、0.01–0.99確率クリップはPR #185と同一。対象地点のすべての年・線・区を訓練から除外し、残りの5地点のデータでのみ学習した。各地点でM個体数加重二項対数損失を評価した後、**地点を等重み**で平均した。

## 主結果：別の場所へ持ち出すと順位が変わる

| モデル | 地点内・別調査線を評価 | 地点外・その地点名を丸ごと除外 |
| --- | ---: | ---: |
| BASE（基準の紫花率） | 0.720111 | 0.713029 |
| DIST（水辺距離） | **0.609774** | 0.756758 |
| CONGEN（L+Sの相対比率） | 0.695807 | **0.672575** |
| BOTH（距離＋他種比率） | 0.626362 | 0.739312 |

地点外の距離追加利得 `BASE - DIST = -0.043729`（悪化）。**6地点のうち4地点では改善、2地点では悪化**した。これは「すべての地点で距離が効かない」という結論ではない。特にShiga（滋賀）の距離モデルは基準に対して **−0.354971**悪化。Shigaを外して5地点で計算すると、距離の利得は **+0.018519**へ符号が変わる。この6地点の平均負値は**一地点への依存が大きい**。

Shigaの評価個体の **1117/2949（37.88%）**は、他の訓練5地点の水辺距離の最大値35を超える位置にあり、Shiga自体では最大50だった。これは外挿による不安定性を強く疑わせるが、Shigaでの失敗の原因が外挿だけであることを因果的に証明したわけではない。

CONGENを使った地点外モデルでは基準より平均 **+0.040453**低損失、6地点中4地点で改善した。DIST単独よりも平均損失が小さかったが、これは同時に測った他種の分布情報を評価地点で使えるという条件付きの予測であり、未測定の新天地での事前予測や、他種との相互作用の進化効果ではない。BOTHはDIST単独より **+0.017446**だけ改善する一方、CONGEN単独より平均損失は大きかった。これは共変量の重複・正則化・地点差などにも左右される。

## 先に列挙した感度分析

| 訓練設定 | DIST vs BASE 利得（正なら改善） | DISTへCONGENを追加する利得 |
| --- | ---: | ---: |
| λ=1, 全体のM個体重み | −0.044853 | +0.016777 |
| **λ=10, 主解析** | **−0.043729** | **+0.017446** |
| λ=100, 全体のM個体重み | −0.033184 | +0.020931 |
| λ=10, 学習5地点の総重みを等しくする | **+0.002708** | +0.013896 |

**距離モデルが未知地点で基準より悪化するかどうかは学習地点の重み付けでも符号が変わる。** そのため「水辺距離が他地点に転移しない」という絶対的な一般化もできない。今回の選択済み6地点・事前に固定した学習方式では距離の平均追加利得は安定せず、他種共存比率の追加情報は限定的に候補となる、という範囲で読む。

## 原著の意味から逸脱しない注意点

- Takahashi, Takakura & Kawata (2016), PLOS ONE DOI **10.1371/journal.pone.0164381** はすでに、M種紫花と他の白花L/S種の共存との正の関係、および水辺距離との強い交絡を報告した。今回の新しさは**新しい全地点除外の予測比較**であり、「送粉者による生殖干渉を新たに証明した」ことではない。
- 同じ研究から標本数条件を満たして既に選ばれた6地点の回顧的評価で、地理空間的に独立した新しい6場所の前向き予測ではない。`ootaka`と`ootaka2`など距離の近い可能性のある地点名を6回の独立した進化機会と解釈しない。6,692個体を独立した進化反復としない。
- 他種の比率 `(L+S)/(M+L+S)` は目的変数の紫白割合 `v/(v+w)` と同時期の資料から計算する説明変数。調査前に容易に得られる独立な外部環境測定ではない。他種を人為的に増減する介入実験の結果ではない。
- 野外データは512調査区、M種紫5081、白8723、別種L4463、S29。**別種の白花をM種の白花に加算しない**。126区はM種不在、距離=-1が3区（うちM種あり2区）は距離不明として除外し、母集団の単型区と誤認しない。
- 距離の単位や物理的意味は原著に従う。場所によって線形な応答が異なる可能性がある。Boecheraに見つかったJudd Falls依存のシグナルや、Linanthusの1谷の繰返しと合わせて、種間一般則として統計的にプールしない。
- **新しいp値や6地点を独立とみなした95%信頼区間は算出しない**。結果を見た後のモデル変更はせず、λ=1/100と地点等重み感度のみ別枠で報告した。
