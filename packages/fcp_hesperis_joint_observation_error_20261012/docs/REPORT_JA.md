# Hesperis：群落間花色差は「抽出誤差＋色判定誤差」だけで消えるか

**2026-10-12。結論：条件付きの否定的証拠が得られた。** 原著に従って小群落は全数、大群落は100個体以上を色に依存せず無作為抽出し、さらに実際の観測色の誤判定が各群落等重みで2%以下という*保証があれば*、観測された群落間差を両方の観測過程だけで説明する「全群落の真の有限個体組成が等しい」という帰無モデルの上側確率は、3年間補正後も年別0.00125・0.00871・0.01569以下になる。

しかし**原著は誤判定率を実測・公表しておらず、採集過程の実施状況も個票で確認できない**。したがって、これを無条件の有意性や原因の実証と表現しない。1種・1研究・公表要約に条件付きであり、新しい独立野外標本ではない。

## 以前の研究から変わったこと

- PR173は公表平均からShannon多様性を群落内・群落間に分解した**記述的**結果。
- PR174は分類が正しい仮定で、抽出だけが群落間差を生む帰無モデルに対する**条件付き確率上限**。
- PR176は抽出差を補正しないまま、正しく判定した同一標本の群落間差に対する**仮想誤判定率の決定論的下限**。
- 今回はこの2種類の誤差を**一つの観測モデル**で結び、エントロピーの情報論的不等式から事象の包含関係を作り、既存の標本抽出MGFへ接続した。確率上限は掛け算ではなく、包含関係と必要時の和集合界による。証明・適用条件は `docs/PROOF.md`。

## 実測と仮定の境界

元データにおける群落×年×白・桃・紫カウント、実際の花色評価個体数、観察者間検証データは未取得。2%は想定値であり、1%・3%・5%のケースもすべて保存している。誤分類が群落別に異なっていても情報論的な境界は成り立つが、各年でその誤分類率上限が守られたという事実は示されていない。確認できない場合、今回は**仮定に条件付き**という判定から上げない。

3色の判定が滑らかな連続形質を粗く区切った点や、同じ群落が年をまたいで現れる点は依然として残る。群落間情報量やp上限は個体群遺伝学のFst、送粉者による選択、色素の乾燥利得、都市環境への局所適応を直接測ったものではない。また「全群落の真の有限個体組成が完全に等しい」という非常に狭い帰無を否定しても、ドリフトによって群落ごとの有限個体組成が異なる可能性は除外できない。
