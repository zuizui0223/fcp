# FCP field distance-gradient transport across unseen population names: frozen exploratory protocol

Date: 2026-10-13 JST. **RETROSPECTIVE, source-exposed**: the original Takahashi et al. (2016) paper, PR185 held-out-line results, and even an initial audit of the six population-wise fitted gradient directions have already been seen. This is **not** a preregistered confirmation of a newly discovered species-wide pattern.

## Question

The previous PR185 found within-site water-edge distance predicted M-purple vs white morph counts better than each site's prevalence in **all six source populations**. Do the *sign and numerical size* of that shoreline gradient generalize **between named source populations**, or must the gradient be estimated anew from within each population? Specifically, can an equal-population median water-distance coefficient trained on the **other five populations** improve unseen-line M-flower colour predictions in the sixth, after allowing **only its background purple frequency** to be calibrated from other lines of the sixth population?

This is a falsification/transportability analysis, not a mechanism/selection test. Authors already report that purple is associated with nearness to water in **most** observed populations, without a universal direction claim.

## Models compared on the **same original heldout lines**

1. **BASE (parent)**: within-site target training lines, Jeffreys `(V_train+.5)/(N_train+1)`, clipped .01..99; immutable PR185 base prediction and score.
2. **LOCAL_DIST (parent)**: within-site target training lines, one penalized logistic water-distance slope with ridge lambda=10 on plant-count-weighted within-training-site standardized `distance`; identical PR185 code/results; immutable.
3. **BORROW_MEDIAN (new primary)**: for each target named site `s`, fit **one** local ridge-binomial distance slope separately to the **complete original siteyear observations** of each of the other five **named populations**, using the exact same Jeffreys intercept, lambda10 ridge on within-source-site individual-weighted standardized distance. Convert each fitted slope to *logit per one original source distance unit* by dividing by that source site's weighted distance SD. The shared coefficient is the **equal-site median** of these five coefficients, so no larger site dominates and one extreme source slope is robustly downweighted. This source coefficient is held completely fixed when a line at site `s` is withheld. On the `s` training lines **only**, estimate ONE intercept with this borrowed slope and the same 0.5/0.5 Jeffreys pseudo-count centred at the **training-line-weighted mean distance**, using a monotone root solver. Do not re-fit or choose the gradient from target site outcomes. Apply to the held-out line and the original .01..99 probability clip.
4. **BORROW_MEAN (prespecified method sensitivity)**: identical except use the unweighted arithmetic mean of the other five fitted coefficients; reflects sensitivity to slope heterogeneity, not separate confirmatory hypothesis.

The source slopes use the same source populations' **full original siteyear field quadrats**; this is allowed because they are not target sites in the outer cross-site evaluation. When target `s` is itself a source training population for a *different* target, that is a separate leave-one-population-out outer fold. Never train on any part (including other lines) of the target site to estimate the transferred slope: its other lines may affect **only its intercept**. The source coefficients and each target intercept must be logged.

## Fixed estimands, predictions and robustness

- Score exact target heldout M-individual binomial log loss in nats: `(-v log(q)-w log(1-q))/(v+w)`; exactly same fold/quadrat/test denominator as PR185. The main estimand is the **six-named-site-equal** average `Loss(BASE)-Loss(BORROW_MEDIAN)`; positive = portable gradient helps beyond intercept calibration. Also report `Loss(LOCAL_DIST)-Loss(BORROW_MEDIAN)` as a transport cost (positive = borrowing better than local). For means by site, weight held-out quadrats by M individual counts **inside each site**.
- Record six source fitted gradient **signs and slopes** from full named-site datasets, and signed gradient fitted to each of the 32 target training-line folds. Record the number of fold signs consistent with the full-source site, and highlight opposite-direction sites rather than averaging them away. These descriptive signs were partly seen before protocol; do not calculate binomial sign-test p-values and call them discovery.
- Report each named site separately, including minority/opposite-direction cases; posthoc leave-one-named-site-out numeric means as fragility audit, without selecting a preferred subset. Do not report CIs or p values treating the 6692 plants, 32 source lines or six named sites as independent evolutionary experiments.
- **Sensitivity**: independently computed `BORROW_MEAN` score on same heldout units. Do not tune source shrinkage/magnitude, epsilon, score or source site subsets after seeing any result. No source-area model to predict new sites with no target-site observations is claimed: target-site intercept is calibrated with its other lines.
- The main prediction conditions on recorded **water-edge distance of the heldout line**; this is not true forecasting of unsurveyed environment or newly acquired independent study sites.

## Claims and controls

An opposite sign or loss of portable accuracy is evidence against a **single portable shoreline-distance *prediction rule* across these sampled named places**, not proof of biological adaptation, pollinator competition, drift, a particular microhabitat effect, or the genetic cause of petal pigment. The source paper already noted cross-population ecological heterogeneity. A new result is the **quantified cross-site predictive transportability test**, not the existence of the original within-site shoreline association.
