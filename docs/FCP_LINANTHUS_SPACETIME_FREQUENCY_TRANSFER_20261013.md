# 野外調査で、個体数が変わっても花色の空間的配置は持続するか

2026-10-13。*Linanthus parryae* の公表済み野外カウントを用いた事後的・記述的な再解析。**新しい生物標本、独立な生物学的追試、世界共通の法則を得た研究ではない。** 主論文H1/H2およびHesperis PR173–177は変更しない。

## 観察対象と比較方法

Schemske & Bierzychudek (2007), *Evolution* 61:2528–2543, DOI `10.1111/j.1558-5646.2007.00219.x` Appendix。カリフォルニアの一つの谷の東西で、南北二つのトランセクトを1992–1998年に反復調査した。約2m×2mの区画ごとのデータは入手できておらず、この再解析の単位は同じ調査地内の4つの**集計区間**（北東、北西、南東、南西）。7年×4区、延べ100,500植物個体のカウントに対応する28行を再利用した。個体は年を跨いだ独立反復とみなさない。

主比較は色を見ず、各年4区それぞれ20個体以上の **1992、1993、1995、1996、1998** の5年。1994は計9個体で一部空区、1997は個体0で、白花0%ではなく「頻度未定義」のまま保持する。副解析は各区100個体以上とし、1996を除く4年で比較した。

- **空間／時間の頻度分散**：各区×年の白花比を等重みとし、固定区の平均差（空間）、年の平均差（時間）、交互作用・残差へ正確に分解。これは個体群の遺伝的F_ST、Shannon多様性、気候の分散説明率ではない。
- **未知年予測**：評価年の全4区を学習から除外し、他の年だけから予測。GLOBAL（全区1平均）、SIDE（谷の東／西別2平均）、SECTION（4区別4平均）の3モデルを同じテスト白花頻度に適用。四区×年に等重みの二乗誤差を計算し、年で平均した。成否を「多種の外部検証」とは呼ばない。

## 主な再計算結果

| 項目 | 4区×5年（各区20個体以上） | 4区×4年（各区100個体以上） |
|---|---:|---:|
| 個数比の分散：空間成分 | **99.7915%** | **99.9801%** |
| 個数比の分散：時間成分 | 0.0646% | 0.0042% |
| 個数比の分散：区×年残差 | 0.1439% | 0.0157% |
| 未知年予測・GLOBAL MSE | 0.21900051 | 0.22280049 |
| 未知年予測・SIDE MSE | **0.00078390** | **0.00012958** |
| 未知年予測・SECTION MSE | 0.00071326 | 0.00007897 |
| SIDEのGLOBAL比の誤差低減 | **99.6421%** | **99.9418%** |

これは区の東西差が支配的という、出版済みの野外事例についての**追加定量**。99%以上は選択効果や環境説明率でなく、4区×指定年の**観測花色頻度の平方変動**に対する割合である。モデルは色の計数に基づく探索的な領域基準であり、未来の独立試験で確証された予測器ではない。

主解析で年間個体数は707–45,055（**63.73倍**）に変動したが、東側の白花が高く西側では青花が優勢という配置は各年で共通。より十分な個体数の四年間（1996を除く）では東−西の差は93.7–95.0ポイントだった。原著がすでに地理的境界の安定を記述しているため、この結果を新しい自然選択の発見と宣伝しない。

## 重要な制限

1. 同じ野外調査地の4区を繰り返した **1種・1景観**のデータ。4×5＝20は独立個体群の数ではない。観察個体数100,491も独立の種間反復ではない。分散比に信頼区間やp値は付けない。
2. 区内個体の花色頻度を年ごとに集計し、元の2m×2m小区画の共存を推定していない。区内変異は空間内で均一とは限らない。
3. 未知年予測は学習から年を完全除外したが、モデル仕様は原著結果閲覧後に定めた事後検証。年月をまたぐ同じ場所で地理的位置を既知とした予測であり、新地域への一般化ではない。
4. 原著では中立アロザイムが地理的花色境界と一致せず、交換移植実験が在来色型の適応度優位を示したと報告している。これは原著の別証拠であって、今回の頻度分散だけが選択・遺伝的浮動・移住の効果を識別したのではない。
5. 元表の1992年・南西の記載「白1.2%」は青1357・白26の計数から計算すると **1.87997%**となり不整合。全解析は整数カウントを用い、転記した印刷率を改変せず監査表へ残す。
6. Hesperisの群落間**Shannonエントロピー**と、今回のsection-year白花**頻度分散**は違う指標。研究間で99.8%と22–26%を単純に大小比較しない。

- 追加公開データ探索では、*Digitalis purpurea*（Figshare 29095451）、*Anemone pavonina*（Figshare 31301656）、日本産*Sisyrinchium*多型（Dryad j8q34）の具体的データリポジトリを確認したが、元CSV・補足ファイルの実バイトがこのセッションでは取得できなかった。生データが取得できたと主張しない。
