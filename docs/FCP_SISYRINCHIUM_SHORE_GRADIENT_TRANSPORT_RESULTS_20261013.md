# ニワゼキショウ類：水辺距離の花色予測は他地点に持ち運べるか

## 結論

**地点内の距離勾配は既存6地点すべてで未知調査線の予測を改善しましたが、他の地点から同じ距離単位の勾配を借りる予測には一般化しませんでした。** また、6地点のうちBanpakuだけで距離勾配の符号が逆転していました。距離の標準偏差を地点ごとに揃えた追加の診断では、他地点からの予測に一部の共通性が見られました。ただしこの標準化は主結果を確認した**後**の探索的感度であり、独立検証や事前登録済みの共通則ではありません。

## 元データと観察単位

- 原著：Takahashi, Takakura & Kawata (2016), *PLOS ONE* 11:e0164381、DOI `10.1371/journal.pone.0164381`。研究者は既に「多くの個体群で水辺との距離に沿った花色の傾きが見られる」と記述しています。今回の方向の不一致が新しい野外発見というわけではありません。
- 原著Dryad `10.5061/dryad.j8q34` と同じDOIを保持する公開Zenodo record 5003124の原 `data.zip`（127502 bytes、MD5 `008ec196aa5acb769dbfd36e835e32ba`、SHA256 `4859b803af66db1f8f18796fe08ce2581363258444de715f1e9f2f988c5`）。元 `frequency.txt` のSHA256 `a12cdf46483a6d8b78bd00110c196a25f3c8849967ae8a2c37d6aee3d29f516e`。
- 元の512調査区、M種紫花5081・白花8723。別種のL（4463）・S（29）はM種の白花と混同しません。126区はM種不在、距離不明3区（うちM種在2区）を保存台帳で区別します。
- 評価対象は**前回PR185と完全に同じ6地点名／32本の除外調査線／168調査区／M種6692個体**。残りの元データを独立した新しい個体群と数えていません。

## 同じ未知調査線に対する予測精度

| モデル | 地点等重み予測対数損失（低いほど良い） | 基準との差（改善なら正） |
|---|---:|---:|
| 地点内の平均頻度（BASE） | 0.720111 | — |
| 同地点の別調査線から距離傾きを学習（LOCAL_DIST、親PR185） | **0.609774** | **+0.110337** |
| 他の5地点で学習した距離1単位あたりの勾配の中央値（事前固定の主解析） | 0.846716 | **-0.126604** |
| 他の5地点で学習した勾配の算術平均（当初の方法感度） | 0.818402 | -0.098290 |
| **追加診断（事後）**：各地点の距離の標準偏差を揃えて他地点の勾配中央値を適用 | 0.658185 | +0.061927 |
| **追加診断（事後）**：標準化した勾配の算術平均を適用 | 0.689403 | +0.030708 |

他地点から勾配を借りたモデルの**切片だけは、対象地点の他の調査線で補正**しました。係数そのものには対象地点の花色情報を利用していません。その意味で「他地点からの勾配移植」であり、**新地点を花色の予備調査なしに予測できたわけではありません**。元地点の距離の単位・観測幅が違い、距離1単位あたりの勾配を共有させるのが適切か自体も検証対象です。

- **5/6地点の距離勾配は負、Banpaku Y13だけは正**。各地点の32本の除外調査線で傾きを別々に推定しても、32/32本で地点全体と符号が一致しました。サイト単位の小標本ではあり、勾配の進化的独立反復が32あるということではありません。
- 主解析の生勾配移植は3/6地点で地点平均に勝ち、平均は**悪化**しました。Banpaku除外でも地点等重みの改善量は `−0.01623` と負で、Shigaでは傾きの強度差が大きく影響しました。固定の1%–99%確率クリップの使用状況も台帳に記録しています。
- **事後**の距離標準化勾配では5/6地点で基準を上回り、Banpakuでは逆向きのため悪化しました。標準化中央値は同地点の自前距離モデルより平均で `0.048410` nats/個体悪いままです。
- 事後標準化モデルの地点1つ除外では、基準に対する予測改善は `+0.03907～+0.10225` の範囲です（**推論上のCIではない**）。

## 生態学的に言えること・言えないこと

同じ研究で野外で調査された地点では、岸からの距離の**予測的関係が地点によって異なる**ことが確認できます。これは単一の共通線形勾配をそのまま移植する一般化が難しいことを数量化したものです。距離標準化により一部の予測性能が回復するため、「他地点へ距離関係は一切持ち運べない」とも言いません。
一方、原因候補（局所水分環境、他の白花種L/Sとの生殖干渉、送粉者相、群落形成史・遺伝的浮動・多回侵入・局所適応）は分離できません。元論文も水辺距離と他種頻度の共変を指摘しています。符号反転を適応の証拠としないこと、今後の多種C/S一般則として採用しないことが重要です。

**この解析は資料と以前の花色応答を見た後の探索的な統計的輸送検証です。** 6個の地点は無作為な地理的実験の独立標本とはみなせず、p値・標本外CIで一般的生物学的普遍性を主張していません。PR185の予測対象を変更せずに比較しており、過去のH1/H2・PR170–185の結果は変更していません。

- 全6地点の源傾きを元512行から再推定し、各対象地点の**他5地点のみ**から転用係数を求めました。対象地点側では評価線以外の切片だけを再校正します。
- 本体とは別のソース読み込み・解析的HessianのNewton法で**1112項目の数値・標本確認を通過**しました。最大絶対差 `8.05e-11`。新しい生物標本の別解析ではありません。
