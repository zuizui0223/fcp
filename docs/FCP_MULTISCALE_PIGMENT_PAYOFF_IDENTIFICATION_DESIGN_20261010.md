# 種内・種間に共通する花色の適応度機構 — 検証可能な次期研究デザイン

2026-10-10。**提案であって実証結果ではない**。既存のNew Phytologist論文H1/H2および元データを変更しない。

## 研究の核

花色の同じ生理機能や相互作用が、種内の白／有色多型と、近縁種間の白／有色進化を予測するか。種内・種間で同じ種類の測定（花弁の反射スペクトル、UV吸収、化学色素量、送粉・食花・種子適応度）を行い、環境に伴う相対適応度の符号反転と独立系統への予測輸送を主要結果とする。

## FCPの50:50の正しいベースライン

42,111種の機会母集団のうち元1写真の花色分類成功は18,457種。85,337 taxon×cell写真のうち39,075が色分類成功。異なる元地域から分類成功写真5枚以上の1,165種では、種等重み白率48.34%、写真で白のみ231種、有色のみ255種、両方679種。観察白率25–75%の種は24.03%のみ。写真白率の分散の61.46%は種間（有限写真数の近似補正56.56%）。よって世界写真組成50:50を各種・各自然集団の遺伝的平衡と解釈しない。

## 4つの競合仮説

1. **地理的に反対方向の選択**：水分・温度・送粉者・食花者環境を入れ替えると白と有色の相対的な種子／花粉適応度が逆転する。同所50:50は不要。相互移植・共通園で否定可能。
2. **負の頻度依存選択**：総花密度を固定し、白率20%・50%・80%を無作為化した反復野外配列で、希少色型ほど花粉授受／種子生産が高まる。頻度操作で否定可能。
3. **資源配分とストレス防御のトレードオフ**：同じ遺伝背景で水分・光条件を操作し、色素化学量と花数・繁殖配分・生理耐性の相反する作用を検証する。白花もUV吸収フラボノイドを持ち得るので、白＝無色素／無費用とはみなさない。
4. **可塑性・連動形質への間接選択**：同じ個体・家系が季節や乾燥で花色だけでなく花形・開花期間・花数を変え、花色そのものへの適応的選択は存在しない可能性。繰返し個体撮影と家系×環境を検証する。

## 実証計画

**Phase 0（直近）**：元の405枚の花弁／苞葉／別種混在／白飛びと可視色を2人が独立ブラインド判定。既存1,165種について、実際に自然集団で両色個体が共存する証拠、家系追跡、器官・色素経路、系統樹の直接サンプルを確認。画像白率だけで同所多型候補とは判定しない。

**Phase 1（種内）**：遺伝的二色型の確認された4–6種を複数属から候補化（規模はデータ取得可能性・パイロット検出力次第）。各種で複数集団、複数個体・家系を追跡し、水分操作×送粉補助／送粉アクセス×食花・植食排除の独立効果を順番に検証。花数、花粉移動、種子数、発芽・生残と植物全体の適応度を測定。別実験の固定花密度20/50/80%色型比操作から頻度依存的相対適応度を推定。匂い・蜜量・花形・開花日・花サイズも同時計測する。

**Phase 2（種間）**：種内実験系と同じ色素経路が使われる近縁の白／有色種・独立分岐を、複数属から事前に候補選定。直接採取した標本による種系統樹と色素分析がない属レベル仮系統配置では共有適応度機構を推論しない。種内実験で学習した環境×色の相対適応度から、未観測の近縁種における有利色の方向を予測できるかを検証。単純な種間色×降水量相関は共通機構の主要証拠にしない。

**Phase 3（分岐）**：共通機構／種内限定／種間限定／両方非支持をすべて事前に許容する。主解析は色型×環境・色型×頻度の個体適応度相互作用。分類色ラベル、受粉、色素濃度、種子適応度と独立な系統の情報をそれぞれ独立に測る。

## 50:50を進化的平衡として検証する条件

自然集団の実個体白率をp、同じ場での相対適応度差をs(E,p)=log(W_white/W_coloured)=a(E)-b(E)(p-0.5)とする。b(E)>0の負頻度依存かつ0<p*=0.5+a(E)/b(E)<1の時のみ内部安定平衡を示唆する。p*=0.5には別途a(E)=0が必要。全球写真50:50からこの条件は導けない。実地で頻度と適応度を操作して推定する。

## 既存分析と外部先行研究

FCP #135: 全球白率と種間／種内分解。FCP #156: 同じ14,776写真の降水Brier増分は種内+0.0003275、種間−0.0000044だが両者の差の信頼区間は0を跨ぐ。現行FCPには適応度・遺伝色型の確認がない。すでにDactylorhiza sambucinaの希少型利益（2001）、Boechera strictaの植食・乾燥相互作用（2018）、Moricandia arvensisの非適応的白花可塑性（2024）、Abronia fragransの色素・花数・食害（2025公開）の事例があるため、単に色素トレードオフの存在を示すことは新規性不足。**複数独立系統の種内適応度関数から未観測の種間色型進化を予測できるか**が本研究の中心的な新規性となる。
