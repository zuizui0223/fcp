# Non-flower-colour trait feasibility calibration — Tundra Trait Team

A useful result from the superseded development branch is retained as **calibration provenance only**.

The archived Tundra Trait Team dataset contained 91,970 rows across 18 trait variables. Under a fixed physical-support rule—at least 20 species overall and at least five species with >=10 records, >=3 sites and >=50 km geographic span—**14/18 traits passed**.

Four examples with strong support were:

- SLA: 899 species overall; 88 spatially eligible species;
- LDMC: 754 / 64;
- vegetative plant height: 643 / 79;
- leaf N per dry mass: 399 / 34.

This matters because it demonstrates that the time–space design is not intrinsically dependent on flower colour.

It does **not** test time-space coupling. No temporal-memory coefficient, spatial-turnover coefficient or biological predictor model was computed in the calibration result.

Because the trait values were already opened on a superseded development branch, this cannot be promoted as prospective generalized evidence. The frozen BIEN/AusTraits source order remains unchanged.
