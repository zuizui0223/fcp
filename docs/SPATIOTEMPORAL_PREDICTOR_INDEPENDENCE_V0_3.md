# Spatiotemporal predictor-independence contract — v0.3

The generalized programme now has an explicit predictor firewall.

The key rule is simple:

> **A predictor may not be manufactured from the same biological observations whose turnover it is supposed to explain.**

This matters most for ecological specialization. Partner breadth or entropy calculated from the same interaction edges used to estimate interaction-memory or spatial rewiring would create mechanical predictor–response coupling. Primary specialization must therefore come from an external source or a strictly disjoint baseline sample frozen before response networks.

The same logic applies to context heterogeneity and dispersal/mobility. Context must be measured from independent abiotic or co-opportunity data, and mobility cannot be replaced post hoc by range size extracted from the response observations.

The complete 4 response × 3 predictor eligibility grid is machine-readable in `data/spatiotemporal_memory_turnover_eligibility_matrix_v0_2.csv`.

No generalized predictor value or turnover response has been opened by this amendment.
