# 全環境探索の追加監査：同種固定＋非線形空間勾配（2026-10-10）

## 完了した実行

[原写真85,337件・非線形空間基底を追加した成功CI](https://github.com/zuizui0223/fcp/actions/runs/38013165187)で、元写真IDと花色ラベルを再分類せず、同種内の異なる地域から学習・評価する比較を実行した。元の85,337種×セル写真、39,075花色判定可能、46,262判定不能の分母を維持。100,543個の元観察写真位置へ割り当て済みのWorldClim（BIO1–BIO19、日射・風・水蒸気圧）およびSoilGrids 10指標を、種・観察・写真IDの完全一致で再結合した。

従来の「種固有の花色平均＋緯度・経度」だけでは、細かな地理勾配を取りこぼす。そこで実際の写真の緯度経度を地球上の単位球面xyz座標へ変換し、その1次・2次・3次の多項式**合計19空間基底**を追加した。全モデルは地域セル単位の同じ5-fold GroupKFoldと同じ元写真を評価し、種固有の色平均は学習側の別地域写真だけで推定。種ごとの不変な系統主効果は種固定平均に吸収されるが、真の進化的系統距離・枝共分散は同時には推定していない。

## 何が「地理・系統を超えた」と言えるか

**支持：** 同種別の写真平均を学習側だけで推定し、元写真位置から非線形な空間基底を追加した上でも、世界の異なる地域の花色写真では環境全体、特に降水・温度・土壌が、予測誤差を小さくする観測的な追加情報を持つ。この限定的なモデル内での関連は計算結果として保持する。

**まだ支持されない：** すべての地理的自己相関（特に数十km以下や同じ観察者・生育環境）と実際の年代付き**系統共分散**を同時に除いても環境効果が残るという全球一般化。今回追加した球面3次多項式19列は有限個の大域的平滑基底で、空間ランダム場・地理的共分散カーネルの代替ではない。以前に行った真の空間距離カーネル＋実系統Brownian枝共分散の649直接LCVP種での全7環境群追加は、属heldoutと地域heldoutの双方で一貫した改善を示していない。[厳格モデルの実データ](../results/fcp_global42111_all_abiotic_beyond_phylo_spatial_20261010/result.json)。

**生物進化として未識別：** 1種×地域セルの元写真は、その地域集団の花色頻度・遺伝的多型・表現型可塑性・日射の林内実測・訪花者や適応度を表さない。種固定モデルでは、種とともに不変な系統主効果は吸収されており、系統分散と種固定平均を別々に識別できない。LCVP直接種649は元の1,761種の37%であり、環境的に偏ったサンプルなので、厳格モデルの非支持も全球全体に外挿できない。

研究の主線は、単なる「環境と花色の相関」ではなく、**花色の生物地理的配置における種の入れ替わり・空間構造・共通祖先の歴史を超える環境情報を、どの観測尺度で識別可能か**である。結果が非支持・不確定な条件も含めて提示する。

元の1,499種の写真深掘り論文と、独立検証用に未開封の2,000+730種は変更していない。
