# 全球写真100,543枚で検証：白花／有色花の生態学的均衡と相殺仮説

2026-10-10、FCP原データのみを用いた**実測済み・事後的な生態学解析**。新しい写真判定や形質の適応度実測ではない。

## 結論

**写真で白と有色が約50:50に見えるという元観察は再現。ただし、それが「白が多い種の分布」と「同種内の白率変化」が逆方向に釣り合うため、という地理的相殺仮説は支持されなかった。** 全写真の主解析では両成分が**正方向に共変動**した。ただし種あたり5枚以上に限定すると正方向の効果も地理セル単位bootstrapで安定しないため、これを一般生態学法則にはしない。色素合成コストと送粉・防御利益の相対適応度は元写真から測定できていない。

## 原写真の全利用：重複を写真IDで除去

元42,111種のbreadth 1枚/種 = **42,111枚**、既存のtaxon×cell = **85,337枚**。重複写真IDは**26,905**枚で、一度だけ数えると **100,543ユニーク写真、42,111名義種**。元写真の白/黄橙/赤桃/青紫の4分類成功45,953枚、不能54,590枚、元の実写真GPS地点100,348枚。2原ソースで同一写真IDに異なる分類済み色がついた例は0件。未分類写真は勝手に白色・有色へ割り当てない。

**分類可能原写真の白率：21,574/45,953 = 46.95%。** 未分類も含めた何も仮定しない白率の範囲は **21.46〜75.75%**。したがって自然個体群や世界の全植物の遺伝的白率が正確に半分であることは、元画像からは分からない。

元写真の**実撮影緯度**別の白率（セル中央による以前の緯度集計とは異なる）：
- 絶対緯度0–30°：9,247/19,642 = **47.08%**
- 30–60°：11,713/25,033 = **46.79%**
- 60–90°：590/1,204 = **49.00%**

地域別に見ても似た値という**観測事実は残る**。しかし分類できた原写真が100枚以上ある89等面積セルを見ると、セル別白率は**36.64〜62.21%**。9割強のセルが40〜60%に含まれ、地方差と広域の均衡に見える特徴の両方がある。

## 種内・種間で打ち消し合うのか：写真による生態学的相殺検定

同一種の原写真が複数地理セルにある **8,620種、29,464枚**を使った。局所の元写真白率 P は、当該セルの種が全セルで持つ平均写真白率 B と、その種自身の地域偏差 W の合計に厳密分解できる。各セルに写真が30枚以上ある96セル29,117枚で、各種の元写真白・非白の総数、種×セルの出現機会を固定し、種内色ラベルの99ではなく**999回**置換を実行。

| 地理セルの成分 | 実測 |
|---|---:|
| 地域ごとの写真白率 P の重み付き分散 | 0.00260620 |
| 種間構成 B の分散 | 0.00195256 |
| 種内偏差 W の分散 | 0.00029075 |
| **BとWの共分散** | **+0.00018144** |
| **相関** | **+0.24082** |
| BとWが負に共変動する「地理的相殺」片側p | **0.997：支持なし** |
| 正の共変動の探索的片側p | 0.004 |

実測は **var(P)=var(B)+var(W)+2cov(B,W)** に整合。相殺説が期待する負の交差項ではなく正の交差項が得られた。つまり、元写真では「白がもともと多い種がいる地域ほど、同種の写真にも白への地理的偏りがある」という**増幅**方向。ただしこれも「白有色の植物相互作用/適応度」ではない。

**強い限界：** 1種5写真以上に限定したサブ解析の各種写真密度20/30/50/100条件では、正共変動の地理セルbootstrap 95%区間はいずれもゼロをまたぐ。全12感度条件を併記し、疎な種を含めたときだけ強い結果を普遍化しない。負の相殺を支持した組合せは12中0。

## 生物学的な気候仮説は「種内と種間で異なる」

元写真のBIO1, BIO5, BIO12, BIO15,標高,緯度経度を同時調整した観察的な白写真ラベル確率モデル。係数は元写真における説明変数1 SD当たり白写真確率の変化、95%区間はそれぞれ属/種でクラスタ補正したもの。

| 要因 | **種間：25,028種**（種等重みの全球平均写真白率） | **種内：8,619種、29,427枚**（種内平均を除去） |
|---|---:|---:|
| 年間降水量 BIO12 | **+0.04780**［+0.03595,+0.05965］ | **+0.00069**［−0.00786,+0.00924］ |
| 降水季節性 BIO15 | −0.00566［−0.01532,+0.00400］ | −0.00533［−0.01241,+0.00176］ |
| 最暖月気温 BIO5 | −0.00122［−0.02001,+0.01757］ | +0.01474［+0.00360,+0.02589］ |

年間降水量は **種間で白写真ラベルの多さと関連**するが、**同種内の地域間写真の白率変化の線形勾配としては明確ではない**。また最暖月気温に同種内の弱い関連があるが、現行New Phytologistの花−背景/撮影者厳格対照でBIO5が支持されなかったため、花色適応の温度効果とは結論できない。気候の効果・画像分類成功率・種間系統関係の因果を分離できていない。

他方、PR #156の同じ元写真14,776枚を使った種内/種間のBIO12/15追加**Brier予測**検証では種内+0.0003275・種間−0.0000044だった。今回の種平均白確率勾配はその予測量と違うため、単純な数値比較で生態機構が逆とするべきではない。

## 花色の「利益／維持コストのバランス」への本当の判定

**検証できた条件**：
1. 全球と緯度帯では写真白率が約47〜49%で似る：**観測支持**。
2. 種間と種内の地理的偏りが逆方向へ補償して全球比を安定化する：**不支持**。
3. 温度・降水などが同じ向きの白率勾配を種内・種間で作る：**支持なし**（異なる母集団・モデルでの観測候補のみ）。
4. 色素形成の利益、維持コスト、頻度依存繁殖、送粉・防御、種子・花粉適応度により白と有色が均衡する：**元写真には必要な測定がないため識別不能**。

現状は「白／有色の色素トレードオフによって全球の頻度が半々に進化する」という説を支持するのではなく、**分類済み写真を使った世界的な近半々が種内／種間構成の地理的相殺ではない**ことを示した。利益・コストの適応度説そのものが否定されたわけではない。
