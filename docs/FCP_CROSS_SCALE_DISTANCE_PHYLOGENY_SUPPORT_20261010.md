# FCP：地理距離・系統を越えた種内／種間の共通環境要因（2026-10-10）

## 判定：強い意味で共通して支持された環境要因は0件

これは証拠の不在を生物学的効果ゼロと断定するものではない。種内の地理空間モデルは同じ種の固定切片で系統間の恒常差を吸収するが、実際の種内集団系譜を明示的に推定しない。種間の年代付き実系統樹+実撮影地点距離モデルは系統先端の直接被覆率が342/872=39.2%、649/1761=36.9%しかなく、事前50%基準を満たさず全体へ外挿不可。

## 七つの物理要因（実測済みソースを横断）

種内欄：同じ名義種の別地域の元写真を用いた、学習専用の種固定切片＋真の写真地点距離の低ランク空間カーネル＋他の環境ブロックを調整した予測改善。順に気候のみ250/1000km、気候土壌完備250/1000kmのうち、地理セルと種クラスタの両95%区間が正だった条件数。土壌は気候のみには存在しない。

種間の実系統+空間欄：年代付きLCVP直接先端と写真実地点50/250km空間カーネル、属／地理セルholdout、250/500kmの抽出母集団の組み合わせにおいて正の95%区間だった条件数。探索的な個別正区間であり多重比較を通った数ではない。

| 要因 | 種内：距離カーネル後の追加予測で正 | 種間：実系統＋空間後、個別正区間 | 種内局所ペア：全変数maxT補正後 | 全スケールでの判定 |
|---|---|---|---|---|

**環境全7ブロックをまとめた種内予測**では、距離カーネル250/1000kmの気候完備データ（20,546元写真・5,127種）でBrier減少+0.001254/+0.000753、土壌完備（11,136元写真・3,401種）で+0.003076/+0.002333。これに対し、実年代付き系統樹と空間カーネルの両方を明示した種間モデルでは全ブロックの条件付き予測改善は**0/16モデル**でしか95%区間の正支持がなく、実系統の被覆率も未達。これらは異なる母集団・推定量であり、単純に差をとらない。

## 降水量が『最有力候補』であって『共有原因』でない理由

1. 種間：13,307種・1,417属の種間・属内比較でBIO12/15の追加Brier改善+0.001367（セルbootstrap CI +0.000882～+0.001865）。真の写真地点の属内群を250km以内872種、500km以内1,761種に絞った粗い群ラベルnullではp=.010/.015。
2. しかし**真の写真地点50/100km以内で交換する帰無モデル**に替えると250km母集団のp=.350/.175、500km母集団のp=.880/.295で再現せず。地理的残差を真に取り除いたと主張できない。
3. 種内：同種の別地域写真に対する全環境予測では降水ブロックは250/1000kmどちらでも小さく正の予測増分（気候群+0.000433/+0.000335、土壌群+0.000704/+0.000605）。一方、種あたり最も近い1対の写真に限定した元写真の地理条件付き符号反転maxT検定では100/250/500kmの気候・土壌群すべてで全35変数中、補正後支持因子0件。50kmは異色ペア不足でHOLD。
4. さらに、種間の直接年代付きLCVP系統先端＋真の地理距離空間カーネル（群・波長・holdout合計16条件）で降水ブロックは0/16。したがって降水による局所適応、両スケール共通の因果効果は未証明。

## その他：環境要因と混同しない構造上の支持

- 種内：50km近隣写真で花色discordanceが種全体の色構成固定帰無モデルより低い。Discovery+0.020529（166種）、Validation+0.018673（181種）、Third+0.014685（204種）、各p=.005。25/100/250km、撮影者排除、白除外、9色連続量でも方向的頑健性あり。ただし地理構造であって『距離を越えた原因』ではない。
- 種内：写真の重複ペアを解消しても、1/5/10km近接地点写真間引きでも局所色集中が残る。PR #149–153のsource-locked検証。ただし独立遺伝個体は未確認。
- 色空間の非ランダム方向：将来種群の凍結白／有色軸はW=0.517 vs構造帰無中央値0.457、p=.001。同じ撮影・色分類系での表現型幾何学の再現であり、外部独立測色、生化学、選択の実証ではない。
- 高深度種内BIO5（最暖月気温）にIBD調整後の弱い環境類似性（partial rho .00925/.00826/.01019）があったが、Validationの花－背景差ではrho=-.00328、p=.82、同一撮影者ペアも不支持。BIO5を頑健な種内温度選択要因へ昇格しない。
- 広範な系統樹全体における種ごとの花色多様度Dの系統シグナルも元検証で非支持（validation K約.06～.071、p=.27～.41）。これは系統無関係を意味しない。実系統＋空間の局所ソースでは系統自体が予測に寄与する条件もある。

## 未識別の機構

送粉者、食害、アントシアニン濃度、土壌水分の実測、繁殖保証、自殖、個体ごとの遺伝子型と種子適応度について、同じ元写真の個体・種・地域に結合できる厳格な共通因果結果は**まだない**。原研究11系と写真コホートの重複は3種、実際の画像と遺伝子型／適応度の直接結合は0。別の繁殖系統データ3原ソースの直接重複は27/38/44種で確認ゲートHOLD。全て将来検証すべき仮説で、支持された要因リストへ加えない。

## 共同支持の判定ルール

『候補』＝特定のsource-backed geography/lineage-conditional out-of-sample予測増分が正。『厳格支持』＝実撮影地点の局所交換可能性に配慮した帰無モデルを通り、実年代付き系統樹と地理距離を同時に扱う比較でも再現し、母集団の被覆率条件を満たす。後者を満たす物理要因は現時点で0。予測Brier・一致率・生態適応度・事後探索p値を合算しない。
