# Supporting Tables S1–S2 — global photographic variation, high-depth colour structure and ecological limitations

**Reporting-only editorial tables, 14 October 2026.** The source manuscripts and immutable data/CI receipts control every estimate. The table entries are **not nested species filters**, and the same photo IDs or taxa appearing in different analyses do not constitute independent biological confirmations. Worldwide photographed floral-colour variation is **not** genetically verified polymorphism prevalence.
