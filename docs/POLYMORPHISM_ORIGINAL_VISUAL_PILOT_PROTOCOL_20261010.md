# FCP original-image colour-blind visual pilot — strictly internal (2026-10-10)

## Rationale

The existing high-depth FCP finding about geographical allocation of photographed flower-colour variation has undergone observer, month/year, label-composition, photo-disjoint pair, edge-support and source-photo geographic-spacing falsification tests. None can establish that the frozen computer vision pipeline chose the correct flower organ or correctly identified the coarse visible colour in the original photo. Previously, the 405-source-photo blinded review queue and exact-SHA photo byte reavailability (405/405) were validated but no botanical colour was independently adjudicated.

This separate task prepares the actual ORIGINAL photograph pixels needed for colour-blind scrutiny of a bounded 24-case pilot without accessing any of the original machine labels, case leverage/control assignment, species or geographic location. It deliberately does NOT assert two human experts have reviewed the images.

## Source firewall

- Uses only the exact 24-case original frozen pilot manifest: SHA256 `06191b36eca9862f6241b5110ae13aee0ff7e7414a5caaaa1025daffca33eadd`; columns only audit_case_id, original integer photo_id and frozen image SHA256.
- The photograph search is restricted to the original CC-licensed iNaturalist open-data S3 bucket for each exact source photo ID, size large/original, extension jpeg/jpg/png. Never use a private/proprietary photo host, arbitrary URL, image generator or photo replacement.
- Verify downloaded original image bytes against the SHA256 used in historical flower measurements. An unavailable or changed image is a technical non-availability, never a flower colour.
- Generate two blinded contact sheets with only case IDs, no original species, algorithm colour, source metadata, match type or historical outcome. Keep the photos transient inside a CI job, attach for **one day** for internal, access-restricted research review, and never Git-commit original images. Exact photo creator attribution and licence must be verified for any broader sharing/republication.
- Four synthetic guards cover the blind manifest integrity, refusal to read leaked machine-colour fields, original-byte mismatch, and contact-sheet dimensions. The photo output is only successful when all **24 of 24** source image hashes match.
- This creates reviewer-viewable pixels only. No model-based colour classifications, independent human reviews, cross-tabulations or error rates may be asserted merely from generation of contact sheets.
