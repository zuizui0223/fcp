# FCP — Sisyrinchium の未観測地点への転移検証（結果を見る前の設計固定）

2026-10-13。PR #185 の同一地点内・未知調査線予測が成立した後、その生物学的一般化可能性を厳しく検証する。**元研究と過去の予測結果を閲覧済みの事後的な探索解析であり、事前登録ではない。** 今回の未知地点予測スコアは、この設計を記録してから計算する。

## 科学的問い
「既知の地点では水辺距離がM種の紫花頻度を予測した。しかし、水辺距離と紫花頻度の関係は、未知の地点へ移しても成立するか」。元論文の種間生殖干渉仮説の因果性は今回の観察予測では判定しない。

## 凍結した原資料、単位、対象

- 新しい「地点を丸ごと除外」訓練では、評価地点名の**全年・全調査線・全区を訓練から除外**する。訓練可能な他の5地点の前回適格最新年の M>0 かつ水辺距離>=0 の**すべての区**から学習。モデル評価は前回と厳密に同じ168区（6地点各1つ）だけ。訓練と評価の地点名に交差があればHOLD。

## 主モデルと評価
- 前回と**同一の目的関数・ハイパーパラメータ**：個体数で重み付けした2値ロジスティック回帰、Jeffreys 0.5擬似事前の切片、固定Ridge λ=10、訓練のみで求めた個体重み付き特徴量の平均・SD、予測確率の0.01–0.99クリップ。最適化はPR185で数値的に再現確認された同じBFGS+厳密Hessian Newton精密化。学習時に評価地点由来の集計量や花色は一切使わない。
- BASE：他の5地点のM種の全体頻度のみ。DIST：水辺からの記録距離のみ。CONGEN：他種の比率(l+s)/(v+w+l+s)のみ。BOTH：距離+他種比率。**他種比率の分母のv+wは観察したM種の総数であり、紫白内訳ではない**。この比率は目的変数と同時に観察した共変量で、因果的な時点先行性はない。
- **主指標**：各評価地点のM個体数加重二項対数損失を計算後、6地点を等重みで平均。モデルごとの平均loss、地点ごとの差分 BASE−DIST、DIST−BOTH、DISTとCONGENの比較、改善する地点数を掲載。
- **対照**：同じ168区で前回のPR185「同じ地点内の未知のline」に対する既存の予測をスコアし直す。対照は評価地点の別lineを訓練に含むため、**未知地点の予測との比較は厳格なデータ可用性の違い**であって純粋な情報量の因果差ではない。
- **あらかじめ列挙した感度**：①他地点の訓練を全体個体数で重みづけする主解析に加え、訓練で各地点の総重みを等しくした場合、②λ=1および100（主設定λ=10は不変）、③地点をひとつずつ主指標の集計から除外、④評価地点の距離が訓練地点の距離分布の範囲外となる区と、他種比率が範囲外となる区の割合を記録。感度は事後的ではなく予め分析項目として列挙したものだが、この全研究は探索的。
- 6地点しかないため独立生物地理単位を多数持つと扱わず、新しいp値/95% CIを作成しない。M個体数を独立した6,692個の生態学的反復としない。地理的近接するOotaka/Ootaka2を独立した自然進化反復と呼ばない。
