# ニワゼキショウ類：水辺からの粗い距離勾配を固定しても、花色の局所的な偏りは残るか

2026-10-13。前回PR #183の原著再解析を、**元の調査線内における近距離／遠距離の色型総数まで固定する帰無モデル**へ拡張した。研究設計は元のデータと前回の結果をすでに閲覧した後に固定したもので、**探索的・資料公開後の解析であり、外部事前登録でも新規野外調査でもない**。

## 主結果（主検定）

元データはTakakura・Takahashi・Kawataのニワゼキショウ類（`Sisyrinchium` M種）の **512調査区、16地点年（13地点名）、紫花5081個体・白花8723個体**。同所的な他の白花種L=4463、S=29はM種の白花に含めない。M種がいない126区も保持し、無理に単色区にしない。

前回PR #183の調査線内比較の11地点年から、**10地点年（9地点名）**が距離区分の帰無シミュレーションの事前に固定した支持条件を満たす。**Hirose Y13は十分な比較可能個体が27個体で、事前閾値30未満のためHOLD**。距離値−1の3調査区は距離不明の独立区分として記録し、実際の水辺距離に見立てて並べない。

| 指標（10地点年等重み） | 値 |
|---|---:|
| 元の観測された区間花色多様性 B | **39.44%** |
| 調査線×近／遠区分の色型総数と区ごとの個体数を完全固定した帰無期待B | **33.06%** |
| **期待値を超える局所偏り（Δ）** | **+6.381ポイント** |
| 9,999回の条件付き花色ラベルの無作為配置 | **片側 p=0.0001** |
| Δが正の地点年 | **10／10** |
| 最新年のみ各地点を1回計上（9地点） | **Δ=+6.261ポイント、p=0.0001** |
| 地点年1つずつ除外した追加診断 | **+5.424～+6.960ポイント、全て p=0.0001** |

**結論**：調査線間の頻度差と、同一調査線の観測された距離の**粗い近／遠二分**に沿う頻度差、区ごとの有限個体数による偶然の偏りを合わせても、**記録された調査区単位の紫花／白花の空間偏りを説明しきれない**。元データを同じ地点でさらに細かく集計した条件付き無作為ラベル検定の結果であり、適応・生殖干渉・遺伝的分化や新種での独立追試ではない。

## 以前の帰無モデルと今回の関係

同じ10地点年に絞ると、前回の「調査線の色型総数だけ固定」した余剰成分は **+20.634ポイント**。今回の近／遠区分まで固定した帰無モデルでは **+6.381ポイント**。**+14.252ポイント、元の余剰成分の約69.1%分**が二つの条件付き帰無モデルの*基準値の違い*で縮小した。**これは水辺からの距離が69.1%を原因として説明したという因果分解ではない**。任意の区分と観察された色型総数を帰無モデルに固定するほど、維持したパターンは説明対象から外れるためである。

## 事前指定の代替・強い区分の感度分析

調査線内で観測された距離の一意値を近い順に2値ずつ束ねる「隣接距離ペア」でも、**10地点年、Δ=+6.377ポイント、p=0.0001、10／10地点年で正**。最新年9地点のみでは **+6.166ポイント、p=0.0001**。一地点年ずつ除くと **+5.830～+6.885ポイント**の範囲で維持された。

ただし、ペア区分は主解析の中央値二分に**必ずしも入れ子にならない**。連続距離の精密な調整と同値ではなく、両帰無の期待値やΔを「距離をさらに強く調整したから必ず小さくなるはず」と順序付けしてはいけない。今回の2つは、距離を花色を用いず事前に区分した**別々の有限個体数帰無モデル**である。

## 生態学的解釈と重大な未識別部分

原著Takahashi et al.（2016）は、他の白花種L/Sの多い調査区で紫花M種が多いことと、他種の相対頻度が水辺距離と強く共変動することをすでに報告している。前回PR #183では、他種との近接を調査線内で確認できたが、同じ線内の水辺距離の線形成分を引くと12～13ポイントの差が約1ポイントになり、Banpaku Y13の1地点年を除くと支持されなかった。

今回わかったのは**粗い距離区分だけでは調査区内の花色配置を全て吸収できない**という観察上の制約であり、**水辺距離と独立したL種による生殖干渉**は新たに支持していない。距離区分内に残る連続距離・湿度・地形・他種分布・個体群史・調査区配置・空間自己相関などの説明は区別できない。実際の植物をランダム配置した実験でもない。

今回のp値は**観測された地点年・調査線・距離区分・各調査区のM個体数・各距離区分の紫白総数を固定した花色ラベル交換可能性**に対する条件付き基準値。**10地点年が独立進化の10反復とはならない**。2026年時点での公表済み2006–2016観察記録の事後検証として慎重に扱う。
