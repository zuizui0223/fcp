# 全球42,111種：同じ属でも降水と白花の関係は地域によって変わるか？（2026-10-11）

**成果分類：元全球写真の事後探索的な生態学検定**。利益・コスト・適応度を測定した研究ではない。元New Phytologist本文H1/H2とmainは変更しない。

## 対立する生態学的仮説

- **単純な植物相構成仮説**：東経90–180度で「多雨ほど白」の関連が強いのは、そこに分布する属が西側と異なるため。もしそうなら、**両地域に同じ属を限定**すると傾き差は縮小する。
- **同属内の地域文脈仮説**：同じ属でも地域ごとに白／有色の分化と環境との組み合わせが異なる。構成を同じ属に限定しても傾き差は残る。
- **共通の直接的な乾湿応答仮説**：同じ種も多雨側で白が多くなる。この場合、**両地域で実際に撮影された同一種**の白率差とその降水差に共通の正の傾きが現れる。
- **一律色素コスト説**：地球上で白が湿潤環境に適応しやすいなら、同じ属・種に限った地域間でも方向が共通となるはず。ただし写真だけでは色素投資や個体適応度は測定できず、この説の必要条件を直接特定できない。

### 元source再実行後の不可欠な頑健性補正

## 生態学的解釈と次に絞る仮説

**観測で支持できる部分**：東側の多雨–白の正関係は、単純に「東側に白くなりやすい属が偏在する」ためだけではない。同一属を地理的に対応させても、地域×環境の文脈依存が残る。これは種間組成あるいは形質分化と環境との地理的な結び付きである。

**支持できない部分**：全球共通の白／有色の適応度、同じ種の降水量に対する正の変化、色素維持コストの軽減、送粉者の視覚的誘引、食花・乾燥ストレスの防御利益、遺伝的に独立した白化回数。元写真は色素の化学・植物個体の適応度を含まない。属固定効果は年代付き真の種系統樹補正ではない。また地域選択は事後的で、原写真の白判定と分類機会は画質・観測者に依存する。

**仮説の更新**：「白化は世界共通の乾湿トレードオフの最適点」よりも、**『花色の変化しやすい表現型方向は再現するが、その白・有色の生態ニッチとの関係は同属内でさえ地域に依存する』**方が、今回の全球画像データが示す構造に合う。この仮説は環境依存選択の証明ではない。
