# 全球FCP：中程度の降水環境で同種内の白／有色が局所的に混ざりやすいか

2026-10-11。既存全球100,543ユニーク写真の*事後的観測検定*。**結果：支持なし**。本検定は写真の色状態を扱うもので、色素費用、送粉利益、適応度、遺伝的な集団内共存を計測していない。

## 元データ・問い

- 元ソースの全写真ZIP SHA256 `2d6097ba1b0434632e13bbe79dd78180608a287ff5dabebc770b5c0a2cfb52a0`、原測定100,543枚／42,111名義種。
- 原写真に緯度・経度・年間降水量・4色ラベルのある**45,836枚／25,028種**を色型検定に使用。分類不能写真を除外せず元の観測機会から**降水10分位**を作り、色の正解と見なさない。
- 種あたり元写真3枚以上かつ元4色ラベルが白と有色の両方に存在する**1,553種**の写真を対象として、同じ種・異なる観察ID・距離100／250／500 km以内の写真ペアを探索。
- 元写真の降水10分位のうち両端が乾燥区分[0,1]／中間[4,5]／湿潤[8,9]に入るペアを選び、ペアの白／非白の**写真色ラベル不一致率**を種等重みで計算。元4色間不一致も副解析として実施。
- **帰無モデル**：種ごとの元写真4色の総数を完全保存、撮影地点・元写真ID・観察ID・降水分布は固定して色ラベルを999回種内でシャッフル。中間域の不一致率−両端域の平均不一致率を帰無と比較。3距離×写真数3／5以上の6条件にHolm補正。属クラスターの95%再標本化区間も報告。

## 最大の生態学的制約と既存結果との整合

- 検証できた3距離のいずれにおいても、**同一種が乾燥・中間・湿潤の3区分すべてに局所写真ペアを持つケースは0種**。環境帯ごとの別種比較は、同種における反応規範や真正な負頻度依存的維持を証明できない。
- 100km以内の**全**元同種写真ペアは2,353組（2,247種）、しかし同種内の少なくとも3枚+白と非白の元ラベルを持つ種では乾燥／中間／湿潤の元写真ペアは48／43／45組。局所的な色型の実在や統計的検出力には大きな制約が残る。
- 100kmで種ごとの**近隣写真が3枚以上**となる種は61種。したがって多くは写真ペア1組のみで、同じ場の安定した色型頻度や適応度は推定できない。
- 元の詳細な149,900枚を対象とした別解析では50kmで同種内花色写真の地理的**集中**が発見された。それは異なるサンプリング系の頑健な表現型地理構造であり、ここでの「中程度雨量ほど局所共存する」という異なる仮説の非支持と矛盾しない。
- 顕花植物個体、形質遺伝、UV反射色素、花粉輸出、種子数、受粉者、食害を測定していない。写真の白率が約半々であることや生物学的な色型利得・コストと同一視しない。

## 判定

**中程度の降水域ほど写真上の同種内白／有色混在が最大化するというトレードオフの観測予測は支持されない**。元データから頑健に見えるのは、色分類できた花色の広域的な種間組成・地理的配置であり、局所の維持機構ではない。

局所頻度依存の実証には少なくとも同じ自然集団で独立植物個体を識別した写真または外部個体・繁殖成功情報が必要で、現在の世界写真だけから安定平衡を結論できない。
