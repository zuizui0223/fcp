# FCP：白・有色の種内環境ニッチは分かれるのか？（2026-10-11）

## 生態学的な問い

全球の分類成功写真における白の割合が近いからといって、白と有色が適応度で平衡にあるとは限らない。前段の元写真100/250/500km局所混在検定では、中程度の降水域での色型共存は支持されず、同じ種が乾燥・中間・湿潤の全3帯に持つ局所写真ペアは0種だった。

ここでより一般の生態学的予測を検証する：**同じ種でも白写真と有色写真が異なる環境に記録されるか。その方向が種によって反対でも、差の大きさだけは偶然より大きいか。さらに、その差は種内の地理的配置を条件付けても残るか。**

## 全源写真利用と条件

各種の正確な白/有色元写真数を保存して999回色ラベルを置換。別途、元写真の**同種×10度／20度地理セル内でのみ**色を入れ替える空間条件付き帰無を各999回。12の環境×写真数条件にBonferroni補正。空間条件付き帰無は10度で元データの種内で色交換可能な74種/156枚、20度でも155種/383枚しかないため、地理的独立を完全に確立するモデルではなく、実質的な交換可能性の制約を報告。

### 方向性を見ると

422種で白写真が有色写真よりどのくらい湿潤側か、種等重みの符号付き差は**−0.0204種内SD、p=.621**：普遍的な白→湿潤という方向はない。109種の層では+0.0834、p=.146、53種の層では+0.1071、p=.139：やはり安定しない。

最暖月BIO5は422種の種等平均符号差+0.1373 SD、全種内写真を無条件に入れ替えた帰無でp=.003（12比較補正p=.036）だが、**同じ種×10度地理セル内入れ替えではp=.295、20度ではp=.137**。さらに既存の高深度コホートの元写真ではBIO5効果が背景・撮影者対照で崩れた。**温度への色素適応として解釈できない**。

標高では422種の平均平方差0.657、帰無期待0.673、p=.654でニッチ分化支持なし。降水季節性の平方差は0.740対帰無0.673、p=.048だが12比較補正p=.576で支持なし。

## トレードオフ仮説への推論

**現時点で支持される主な生態学的観測**：種内の白／有色の写真は、無条件の元写真ラベル混合より異なる降水環境に現れやすいという*探索的*兆候がある。しかし実地理セルで色ラベルを固定すると超過が小さくなり、複数の写真枚数条件・環境軸を考慮した後は頑健に残らない。白か有色かの変化方向も系統間に共通しない。

**識別できないこと**：環境ニッチの写真差には分布史、土壌・植生・生息地、撮影者、光条件、別器官、季節、独立した植物個体や遺伝多型の有無が混入する。色素の維持エネルギーコスト、光防御、食害、送粉適応度、交雑・遺伝子流動は元写真にない。広域の白／有色が半々でも、利益・コストの平衡や負頻度依存を意味しない。

この検定は前年候補4種の選定には戻らず、**全45,836写真の機会枠から種内ニッチ比較が可能な全422種**を使用する。これは元FCP H1/H2の新しいconfirmatory testではない。主論文、新prospective未使用種と元色測定は不変。
