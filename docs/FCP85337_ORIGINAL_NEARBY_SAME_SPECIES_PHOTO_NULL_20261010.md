# FCP 85,337 original species×cell flower photos: genuine within-species geographically matched colour-null feasibility

## Why this is the next gate

The original worldwide study has 42,111 original named plant species (18,457 one-photo-classifiable), 85,337 original species×equal-area-cell flower photo records (39,075 classifiable, 46,262 not classifiable) and 100,543 distinct source photo/observation IDs. All 100,543 geographic exposure locations were source-matched before any later environment explorations.

[PR #145](https://github.com/zuizui0223/fcp/pull/145) verified that environmental blocks predict original within-species *cross-region photographed four-colour outcomes* beyond training-only species mean, latitude/longitude and an actual source-photo geodesic exponential spatial low-rank kernel approximation. For 20,546 heldout source photo records from 5,127 source species, adding all climate-related ecological blocks reduced Brier error +0.003378 at 100km kernel and +0.001861 at 500km kernel. For 11,136 holdout source photos from 3,401 taxa with ten SoilGrids properties complete, improvements were +0.005381/+0.003146, all original group-fixed-fit conditional intervals positive. But **nearby heldout photo residual autocorrelation did not uniformly decrease**, and no spatially matched photographed-colour permutation null was run.

Previous *between-congeneric species* photo-colour rainfall association lost apparently positive p=.010/.015 when its null was restricted to 50/100km true source-photo geographic exchanges, becoming p=.175–.880. Therefore a spatial-null feasibility assessment for the **within-species repeated photo** data is mandatory before claiming that 7 abiotic blocks meaningfully exceed finer-than-cell spatial dependence.

Original iNaturalist numeric taxon/observation/photo IDs and `cell_id` must match exactly; no source image can be copied, recoloured, swapped across named species, moved to an artificial cell centroid, or counted twice.

## Microgeography and permutation exchangeability

For each original taxon ID separately, sort its photographed source sites by **original numeric photo ID** and partition into deterministic complete-link microgroups. Each original-source group must contain one nominal species only and all actual photo-to-photo great-circle distances must be within the predefined limits **50, 100, 250, 500 km**. Each photographed site is included exactly once. Permutation groups are chosen by source species IDs and original geographic sites, **NOT by observed flower-colour categories**.

Before any permutation, report for all four distances and both source climate-only/soil-complete photo cohorts:
1. Original unique source species, source classified photo rows and source species with >=2 geographically nearby photographed regions; source true species-photo near-group counts and how many photo pair connections can actually exchange labels.
2. Group class-colour exchangeability *diagnostic* only AFTER defining groups: how many groups and photo records have at least two **different original four-state flower photo colours**; this counts statistical permutation power, not biological genetically segregating alleles.
3. How many of the exact 20,546 or 11,136 preexisting out-of-region heldout photo IDs lie in such groups.
4. A fixed feasibility gate **at least 100 exchangeable original photo records AND at least 10% of the original available classified ecological source photo cohort**. Below this return `HOLD_INSUFFICIENT_NEARBY_INTRASPECIFIC_COLOUR_EXCHANGE` with no p-value; never interpret it as proof that climate has no effect.

No shuffles or source p-values should be fitted until the feasibility gate passes. If it does, any future spatial-photo null must refit the exact source species+geodesic kernel and source environmental models with original within-species microgroup colour frequencies preserved, identical source photo folds and denominators; do not change the distance threshold after seeing significance.

## Scientific distinction

This is about photo-available repeated **sites within nominal species**, not actual repeat photos of one genetic individual or within-population colour morph frequencies. An environmental score after species intercepts and low-rank spatial kernels remains an **observational predictive association**, not floral pigment adaptation. Species-invariant phylogenetic components are not separately identifiable alongside complete species intercepts, so PR #143's direct LCVP phylogenetic branch analysis (selected 342/649 original source species) remains a different, nonrandom support level.

Any infeasible matched-null is a **source identification bottleneck**. It does not negate the positive within-species environmental predictive score but blocks promoting it to a geography-resistant evolutionary selection effect. Original 1,499 high-depth H1/H2, main and unopened 2,000+730 prospective taxa remain unchanged.
