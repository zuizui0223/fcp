# Field-scale floral polymorphism: authenticated source-recovery gate (2026-10-13)

## Objective
Recover raw `Sisyrinchium` morph frequency survey and `Boechera stricta` natural-population flower-colour transect observations, to extend the one-site `Linanthus parryae` frequency benchmark to two **genuinely distinct published field datasets**. This gate inspects data first; it reports NO scientific hypothesis test, independent replication of specific Linanthus longitudinal dynamics, or newly established mechanism yet.

## Canonical input identities (before field data access)
- **Takahashi, Takakura & Kawata (2016), PLOS ONE DOI 10.1371/journal.pone.0164381**, originally archived in Dryad **DOI 10.5061/dryad.j8q34**. Authoritative public **Zenodo mirror record 5003124** claims the same DOI and a single `data.zip` of **127,502 bytes**, **MD5 `008ec196aa5acb769dbfd36e835e32ba`**, with field `frequency.txt`, `fitness.txt`, `morphology.txt`, `nec_col.txt`, `tepal_col.txt`. The Dryad archive is known, but direct Dryad stream returned HTTP403 earlier; **do not bypass challenge**. Zenodo mirror is a distinct legitimate public distribution.
- **Vaidya et al. (2018), New Phytologist DOI 10.1111/nph.14998**, originally archived in Dryad **DOI 10.5061/dryad.q0032**, Zenodo public mirror record **4993384** (same original DOI). Required original `natural_populations_individual.txt`, `natural_populations_plot.txt`, and their specific README files. Verify each file against **Zenodo file-specific MD5 returned by the same record**, not by filename or a guessed checksum. Files contain observations from natural-population transects and plot environmental correlates; **common_garden.txt** is a separate experiment and not a replacement for wild-plant counts.
- Each original file must match hosting repository declared byte length and MD5; missing, wrong checksums, HTML verification pages, or decompression failure -> explicit HOLD with error in `source_recovery_receipt.json`. Accept only HTTPS URLs and `zenodo.org` filenames advertised by matching record IDs, not arbitrary redirects to untrusted domains. Log final content checksum and original URLs.

## Biological observational-grain gates
Inspect every recovered table BEFORE performing an inferential test:
- Is `frequency.txt` **one quadrat, one transect, one independent plant, or an aggregated proportion**? Are original integer counts of white/purple **M-species** and co-occurring L- and S-species present? Distinguish the latter white-flowered **other species** from the M-species white morph; never pool morph counts across species.
- Is the sampling unit within **one field site** rather than an independent population? Link site IDs, quadrat IDs, time/date and denominators. Do not count subquadrats, flower rows or visits as independent spatial replicates.
- Is the Boechera plant-level file individually classified (white/purple) with transect/plot IDs? Any source-selected colour strata or balanced sampling would invalidate morph-frequency inference; inspect README and published Methods for actual recruitment.
- Missing phenotypes, explicit no-plants plots, zeros and sampled-without-replacement census status must remain separate. Never invent denominators or geographic distance from IDs.
- First planned descriptive endpoints: per actual sampling unit M-species purple share with integer denominators; site-specific within-site distribution, uncertainty under observed sampling; co-occurring **other-species** frequency gradient (potential confounding). For Boechera: natural-plot site colour incidence and within-site pigment versus herbivory (if labels/measurement confirm). Only after this audit can analysis protocol be frozen and one outcome chosen.
- Authors already documented reduced M-white frequency with other white species, as well as herbivory/pigment associations in Boechera. A reanalysis is not a new biological finding; substantive new claims require genuinely distinct held-out mechanisms/robustness checks. No causal selection inference from transect correlations.
