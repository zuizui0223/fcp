# FCP全球花色：地理空間・種・系統を超えた全環境予測の現状判定（2026-10-10）

## 主問い：SDMではなく花色形質の条件付き分布

問いは「環境が植物の分布を予測できるか」ではなく、**観察された花色4分類が、地理的位置・空間的類似性・種の固有性・系統共有祖先を考慮した後でも、環境によって予測できるか**である。これらの交絡をすべて一度に除去できる完成済み全球モデルがあるという主張はしない。異なるデータ粒度の解析を混ぜない。

### 1. 同種内：85,337件の種×地理セル写真（39,075件の花色が判定可能）

[全環境＋種固定効果の成功結果](../results/fcp_global42111_same_species_all_abiotic_20261010/result.json)は、**20,546件のテスト写真**で他地域の写真から推定した同種の花色平均と緯度・経度を固定した後、日射・風・水蒸気圧・BIO1–19・標高を含む環境情報の一括追加が4色Brier誤差を **+0.004615** 改善することを示した。土壌も揃う **11,136テスト写真**では全環境一括改善が **+0.007988** で、モデル化した土壌10指標の条件付き寄与は **+0.001487**。種固定効果を使うので種不変の系統主効果は吸収されるが、撮影者・ROI・土地利用・種内遺伝型は制御されていない。

これをさらに[球面xyz座標の3次までの19項非線形空間基底で調整](../results/fcp_global42111_species_nonlinear_spatial_all_abiotic_20261010/result.json)しても、同じ20,546テスト写真で環境一括の追加Brier改善 **+0.002950**、土壌完全11,136件で **+0.005662**。条件付き地域セル・種単位再標本化95%区間はいずれも正。温度は気候標本で **+0.000610**、降水 **+0.000868**、蒸気圧 **+0.000197**、風速 **+0.000144**、日射 **+0.000042**（区間がゼロをまたぐ）。土壌完全標本では土壌追加 **+0.001152**、降水 **+0.001289**、温度 **+0.000805**。非線形空間19項は単なる柔軟な大域的傾向で、**Gaussian spatial field、真の残差空間共分散、Moran Iの消失を保証しない**。この結果だけから「空間を完全に超えた」とは記載できない。

### 2. 種間：実測系統樹と空間共分散を双方入れたモデル

[73,420種の年代付きLCVP大系統樹に直接載る種だけを使う結果](../results/fcp_global42111_full_abiotic_spatial_LCVP_20261010/result.json)をソース検証済み[Actions 38013709667](https://github.com/zuizui0223/fcp/actions/runs/38013709667)で保存した。元の局所500km群1,761種から直接一致した**649種**の気候標本、土壌完全は **518種**。元の250km群872種から直接一致した**342種**、土壌完全 **261種**。本数は全42,111種のランダム代表ではなく、旧々のLCVP直接一致は元局所群の39.2%／36.9%で、直接一致しない種は気温・降水の分布が異なっていた。

**空間**は元写真同士の大円距離に基づく指数共分散カーネル（50km／250km）、**系統**はLCVP年代付き樹での共通祖先枝長をもとにしたBrownian covariance kernel。属ごと／写真元セルごとの別々の5-fold GroupKFoldで同じ種・モデル・foldを比較する。これは固定カーネルを用いたkernel ridgeによる予測であり、年代付き樹の不確実性を周辺化した完全なPGLMMではない。

649種の250km空間スケールでは、地理＋空間モデルに系統を追加した4色Brier改善が、属heldout **+0.051321**、地域セルheldout **+0.054450**。ところが、さらに日射・風・水蒸気圧を含む気候・標高の**6環境群を一括追加**すると属heldout **−0.004952**、地域heldout **+0.002000**（双方の条件付き95%区間はゼロを含む）。追加降水8指標の条件付き改善は属 **−0.004603**、地域 **−0.003613**、追加日射は属 **+0.000399**、地域 **+0.001536**。風・気温・蒸気圧も属と地域の両方で安定した独立改善とはならない。

518種の土壌完全標本では**7環境群全追加**のBrier改善は属heldout **−0.013315**、地域heldout **−0.007356**（地域側区間はゼロを含む）。土壌10指標の条件付き改善は属 **−0.003302**、地域 **−0.004634**。異なる空間カーネル50kmや元250km群でも方向の安定性は確認できない。特定の環境群が一部foldで名目上改善しても、数十項目の探索・共線性・重複した標本を考慮すれば独立の進化適応証拠ではない。

### 3. 判定と必要な次の識別

| 主張 | 判定 |
|---|---|
| 元写真上の花色は種や地理と対応する | 観察的に支持 |
| 同種・別地域の花色写真に環境の追加予測情報がある | **種平均＋3次球面空間傾向を超えて支持**。ただし空間ランダム場未評価 |
| 原LCVP直接一致種間で環境群が本当の空間共分散＋系統共分散を超える | **一貫した支持なし** |
| 全42,111種の進化的花色が環境に適応している | **非識別**。全種の系統樹欠測・写真1件／種・非因果 |
| 直接樹に載る649種の結果を元1,761種に一般化 | **HOLD**。直接樹被覆率36.9%、環境的に偏る |
| 前回の局所降水p=.010/.015は細かい空間構造を超える | **非支持**。50/100km条件付き帰無モデルはp=.175〜.880 |

本研究の主評価は、地理・空間・系統の共有構造に加えて環境群を投入する**同一標本のout-of-group予測差**であり、個別変数のposthoc「当たり」を生物学的機構と呼ばない。日射は気候学的な地表入射日射であり花の実効照度ではなく、SoilGridsは実測根圏土壌ではない。

**今回の最も重要な結論：** 大規模な同種内の観察的花色差には環境の予測情報がある一方、実際の系統共分散まで同時に考慮できる限定的な種間標本では、全環境群は一貫した追加予測力を示さない。この違いは解析粒度・標本選択・色分類・空間モデル仕様も違うため、直ちに進化過程の違いと断定できない。

原稿主張を強めるには、同種内85,337件でさらに**真の空間距離共分散（近似GP／空間ランダム場）**と距離制約のmatched-null・残差空間自己相関を検証すること、別の系統/種群で直接系統を拡大すること、写真花色の再現性と遺伝・繁殖適応度を測ることが必要。

すべて探索的・同じ元写真の再解析であり、元の1,499種詳細研究、確証用に未閲覧の2,000+730種、mainを変更しない。


## 4. 代表写真42,111種の全環境・36個別変数の探索も実行済み

[42,111種の全変数を欠測共通完全ケースで比較した結果](../results/fcp_global42111_complete_multienvironment_photo_models_20261010/result.json)を追加した。元42,111種のうち、元写真の4色が判定可能な18,457種から**日射・風・水蒸気圧・BIO1–BIO19・標高・土壌10変数が全て揃う14,118種**（3,940属、103写真地域セル）を選んだ。すべての比較で同一14,118種、同一5-fold属heldoutおよび地理セルheldoutを用い、元写真を再分類せず、多重探索された陰性・不確実な効果も全件保存した。

- **属heldout**：地理座標のみの4色log-loss **1.179025**、全7環境追加で **1.171897**。全環境増分 **+0.007128**、名目上の属単位固定fold resampling 95%区間 [+0.003019,+0.011582]。
- **写真元セルheldout**：地理のみ **1.180291**、全7環境追加 **1.174628**、全環境増分 **+0.005663**、名目固定fold区間 [+0.001882,+0.009967]。
- しかし**7環境群（標高・温度・降水・日射・風・水蒸気圧・土壌）は、ほか6群を条件とすると、いずれも属・地域の両方で一貫して正の独立増分を持たなかった**。例えば降水全8指標を除外した際のlog-loss増分は属 +0.000803（区間はゼロをまたぐ）、地域 +0.000759（同）；土壌10指標の追加寄与は属 −0.000716、地域 −0.001103（両区間ゼロをまたぐ）。
- 全36個別変数も欠測共通標本で全件評価した。BIO3「等温性」（平均日較差 / 年較差の100倍）の条件付きlog-loss増分は属 **+0.000717** [+0.000035,+0.001493]、地域 **+0.001138** [+0.000226,+0.002155]。日射の月間CVは地域だけ +0.001017 [+0.000192,+0.002004]。**36回以上のposthocモデル比較、元地理の残差自己相関と系統共分散の不足があるため、いずれも有効な独立検証で確認された新しい物理機構と記述してはならない**。

この14,118種解析は**単純な緯度・経度地理統制であり、真の空間残差カーネルや直接LCVP系統共分散を含まない**。従って上記の全球予測改善は、同じページの649種の「空間＋本当の系統樹の共分散の後に全環境を追加しても安定した改善が得られない」と矛盾するのではなく、**異なる識別レベル・系統欠測で選ばれた異なる標本に対する結果**である。

**総合判定（変更なし）:** 環境情報は種間・同種内の元写真予測に追加情報を与える。ただし「全42,111種の花色は環境によって、地理的空間依存性と進化的系統史を超えて適応進化した」という主張は未支持／非識別である。元1,499種の詳細研究と確証用2,000+730種は変更しない。
