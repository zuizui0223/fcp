# Spatiotemporal memory-turnover predictor matrix — pre-outcome amendment v0.2

## Purpose

The v0.1 programme already froze three biological predictor families before any generalized trait or interaction outcome was opened:

- context heterogeneity — primary common driver;
- ecological specialization — primary decoupling candidate;
- dispersal / mobility — secondary decoupling candidate.

This amendment does **not** add a fourth predictor, alter source order, open outcomes, or change any support gate.

It only makes the already stated directional structure machine-readable across the complete 4 response × 3 predictor grid.

Canonical matrix:

`data/spatiotemporal_memory_turnover_predictor_matrix_v0_2.csv`

## Frozen directions

### Context heterogeneity

Higher context heterogeneity predicts faster turnover on all four responses.

- TT: positive
- TS: positive
- IT: positive
- IS: positive

This is the direct common-driver hypothesis.

### Ecological specialization

Specialization is a predeclared time-space decoupler.

- TT: negative
- TS: positive
- IT: negative
- IS: positive

An opposite-sign time/space result is therefore a predicted biological outcome, not a failure that permits predictor replacement.

### Dispersal / mobility

Mobility is a spatial decoupler.

- TT: no directional primary prediction
- TS: negative
- IT: no directional primary prediction
- IS: negative

Temporal mobility effects are reported if estimable but cannot be used to rescue a failed spatial prediction.

## Interaction-space boundary

For IS, the primary biological response remains the rewiring component among shared/available species.

Species-turnover and total-network turnover remain mandatory diagnostics.

No IS result can be promoted as rewiring if the decomposition is unavailable.

## Governance

- Generalized biological outcomes remain unopened.
- Current FCP New Phytologist science is unchanged.
- CHUN Evolution Letters v0.3 and the later hierarchical-memory extension are unchanged.
- Mangal source qualification remains response-firewalled.
- Source substitution remains governed by the finite-family rule in the v0.1 design.
