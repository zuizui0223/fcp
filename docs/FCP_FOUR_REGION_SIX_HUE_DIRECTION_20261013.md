# FCP — 降水量と花色の方向：4地域×6色相対照の同時検証

**2026年10月13日**／対象：`zuizui0223/fcp` のオリジナル花写真。元データ解析の事後的な多重比較感度。生物学的に独立な新規検証ではない。

## 生態学的な問い

東経90–180°で見つかった「湿潤側で白が増え、青紫が減る」という予測的な色相勾配は、他の経度地域・色相対照を一括して評価しても特殊な方向なのか。それとも、以前の解析で注目した地域・色対の選択によるものなのか。

4つの固定90度幅経度区分 `[-180,-90),[-90,0),[0,90),[90,180]` と、白・黄橙・赤桃・青紫の全6組の色相対照で**24候補の1つのfamily**を作り、属で対応づけた環境–花色傾き差を推定。東側・白―青紫は結果を見てから注目したことを明示する。

## 原資料・統計単位

- 全球の元写真機会：**42,111名義種、100,543写真ID**。4色分類済み45,953枚、未分類54,590枚。
- 気候＋元写真の4色ラベルが揃う解析資源：**45,836枚、25,028種**。年間降水量BIO12の共通全球1標準偏差は約736 mm。
- 一度に比較する地理範囲の内外の**双方に別名の3種以上が撮影された同一属**だけを使用：西経180–90で269属、90–0で436属、東経0–90で433属、90–180で394属。
- 花色・説明変数は元の4色、BIO12・BIO1・BIO5・BIO15・標高・絶対緯度・経度sin/cosの8軸を維持。種平均の属内偏差を重回帰し、種等重み・属等重みを別に推定。
- 999回の**共通全球属IDを使ったマルチノミアルbootstrap**を4地域すべてへ同時に適用。地域間で同じ属が両方に含まれる依存を保持。元PR #188の個別地域で属集合内を再標本化したbootstrapとは**別の全域同時再標本化規約**。
- `maxT`: 各24対照のbootstrap推定量の中心化偏差をそのSDで標準化し、各反復で24対照の最大絶対値を求め、95%分位を全区間へ適用。厳格画質は別familyとして同じ24対照を再評価する。地域・色相選択を超える、既往の環境変数/データ深さ/モデル選択の多重性は含まない。

## 元のPR #188との数値一致

東側の白–青紫点推定（全写真で+7.628／+5.309、厳格画質で+9.107／+11.938）は、原資料・母集団・回帰・種等重み／属等重みが同じため前解析と一致。新しい999回bootstrapは**4地域間で共有する全球属再標本化**なので、単一地域用の元bootstrapと名目的区間の端が異なり得る。これはモデル係数の変更や選択し直しではない。

新しい再計算では、元写真由来の8軸・4色の独立重み付き最小二乗実装を用いて**16個の地域×画質×重みの係数／計24×4の対照を224項目照合**、最大絶対差は `3.11e-14`。合成検証は6テストすべて通過。

## 科学的な判定

1. **残る支持**：全分類写真の種等重みでは、東経90–180°の白–青紫相対降水勾配が、この限定した4×6=24候補の近似的同時区間でも正。
2. **頑健性の上限**：各属を1票とすると同時区間はゼロを含む。厳格画質で同時区間は両重みともゼロを含む。したがって地域共通・分類群共通・写真品質非依存の花色–降水法則とは言えない。
3. **推論の上限**：すべて元の公開iNaturalist写真に基づく、選択後・観測的な分布。原画像色の分類・写真の欠測MNAR・送粉者、土壌保水性・熱ストレス・系統関係・地域内空間構造・個体の遺伝子型・適応度による交絡は排除できない。**この結果で局所適応、湿潤環境で白花の方が適応的、色素合成コスト等を証明したとはしない。**
4. **次に使うべき科学的対象**：既存写真で探索を拡張するのではなく、標本を新しく確保して東経90–180°／白–青紫対照と画質基準を開封前に固定し、真正な花器官・色型の専門家確認と地域・属を越える検証を行う。
