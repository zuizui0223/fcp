# 種内の気温関連は、花色の地理的分化にどう接続するか？（2026-10-19）

## 現在の判定

**気温との平均的な正の関連は維持されている。** 1,574種・86,114枚の主環境パネルではBIO5（最暖月の最高気温）と白花ラベルの種内平均対数オッズに正の関連がある（1℃当たり種等重み+0.03233、属ブートストラップ95%区間[+0.01786, +0.04728]）。

これが実際の**種内の地理的な色型分化**と結びつくかを、既存の種別環境傾きと50 km色分化統計から探索的に比較した。**気温との関連の強い種ほど、白―有色の地理構造も弱く大きい傾向はあるが、気温係数の方向との対応は見いだせない。** この結果から気温による局所適応・色素維持費用を推定してはならない。

## 実行データと定義

- 環境：`results/fcp_real_447500_environment_model_20261018/species_slopes.csv`、保存済みのFirth同時モデルから `model=primary, variable=BIO5, status=ok` の**1,574種**を取り出す。
- 地理：`results/fcp_real_447500_white_axis_decomposition_20261018/species_spatial_decomposition.csv` の**1,761種**。
- 共通する種は **787種、448属**。同じ種IDで厳密結合し、元の写真を再分類・再回帰していない。
- 環境傾きの大きさは種ごとの気温SD当たりの標準化Firth傾きの絶対値 `|β_s|`。地理構造は各種の白―有色成分について、`(observed 50-km depletion − mean matched vertex-null depletion) / global white–chromatic mismatch`。
- 主記述はSpearman順位相関。同時推定の不確実性は保持されていないため、傾き標準誤差、写真数、白頻度、気温の観測SD、局所ペア数、白―有色の全域不一致率、元のコホートをランク残差化した**探索的偏順位相関**も計算した。
- 属を丸ごと復元抽出する500回のパーセンタイルブートストラップ（seed 2026101921）で記述的区間を得た。これは**モデルと元のラベル置換を再実行するブートストラップではない**。

## 因果的な解釈を制限する重大な点

**最重要:** 環境傾きと地理的色分化は、**同じ元写真の白／非白ラベルと位置情報から計算されている**。気温そのものが空間的に自己相関しているため、別の原因（遺伝子流動の制限、地理的集団史、写真撮影・分類条件など）で花色が地域的にまとまるだけでも、気温傾きの絶対値は強くなり得る。今回の通常の属ブートストラップと偏順位相関はこの共有データ由来の数学的・地理的結合を帰無化していない。

したがって、偏順位相関の区間が正でも「温度が花色分化を生んだ」「適応的選択が多数種で共通した」とは言えない。**次に必要な実測データ内の反証**は、各種の色頻度・地理座標・気温勾配と観測条件を保持した共同ラベル置換で**温度モデルと空間統計をともに再当てはめ**し、`|β|–地理構造`の観測相関が、その結合を持つ帰無分布を超えるかどうかの検証である。それに成功しても機構確定には中立遺伝子型・共通圃場・適応度が必要となる。
