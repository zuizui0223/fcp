# Archived GitHub Actions workflows

These workflow definitions are retained for provenance but intentionally live outside `.github/workflows/`, so GitHub Actions does not register or run them automatically.

- `jbi/`: historical Chapter-1, 34-species and other JBI pipeline workflows.
- `disttrait/`: reusable-methods development and release workflows.
- `literature/`: historical global-literature discovery workflow.
- `p500/`: historical P500 prospective measurement workflow.

The files are moved without changing their blob contents. Historical documents may still cite their original `.github/workflows/<filename>` paths; for repository-history reconstruction use the original commit, and for the retained frozen definition use the same filename under this archive.

No current New Phytologist numerical result depends on executing these archived definitions.
